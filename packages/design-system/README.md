# Daylight Beacon design system

Task 2 establishes a light-first interface system for Moorish Lighthouse.

- `tokens.css` is the source of truth for color, type, spacing, radius, shadow, motion, z-index, and content-width tokens.
- Palette values are intentionally marked temporary until the owner supplies the original logo for approved color sampling.
- Structural icons and motifs are limited to the lighthouse, crescent, horizon, and light language already visible in approved source material.
- Components consume semantic tokens rather than raw color values.
